## Literature

- [Interesting papers](/#interesting-papers) — reading and discussion list.

- [arXiv: astrophysics](https://arxiv.org/archive/astro-ph) — preprints and new research.
- [NASA Astrophysics Data System (ADS)](https://ui.adsabs.harvard.edu/) — literature and citation searches.
- [Google Scholar](https://scholar.google.com/) — scholarly literature searches.
- [My ORCID record](https://orcid.org/0000-0001-9565-9462) — researcher identifier and works.

## Stellar evolution and data

- [MESA](https://docs.mesastar.org/) — stellar evolution code and documentation.
- [MPA Stellar Model Grid Repository](https://wwwmpa.mpa-garching.mpg.de/stellgrid/) — stellar and binary model grids.
- [SIMBAD](https://simbad.cds.unistra.fr/simbad/) — astronomical object information.
